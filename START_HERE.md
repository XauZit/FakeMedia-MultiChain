# Start here

This is a new GitHub source folder, not a replacement private blockchain workspace.

1. Extract the ZIP to a convenient new directory. Open PowerShell in the folder containing `lab.py` and `README.md`.
2. Run `python -m unittest -v test_lab test_recovery test_mining_permissions test_submission_tools`.
3. Use README route A to point at the existing working workspace. Do not create another chain merely because the source folder is new.
4. Run the live collection block in README. Inspect each result; failed or unknown requests must remain visible.
5. Export allowlisted evidence. Take real screenshots using `report/SCREENSHOT_PLAN.md`.
6. Write your own report in the DOCX workbook and export it to PDF. The reference PDF is not your final report.
7. Follow `PUBLISH_TO_GITHUB.md` and `SUBMISSION_CHECKLIST.md`.

A completed readiness check is evidence of setup, not a successful demo or throughput result. No mark, AI-detector result or compliance percentage is guaranteed.
