# Write the report from your own understanding

The teacher allows no more than 10% AI-generated writing. This folder is an authoring aid, not a certificate of compliance. Generated prompts, captions, diagrams, technical explanations and code assistance must not be presented as independent student authorship. Ask the instructor how code, figures, captions, quoted sources and references are counted.

Read the paper and source code, run the commands, take notes in your own words, then write from those notes. Do not merely paraphrase AI prose to evade detection. Keep drafts and record what assistance you used. An AI-detector percentage is not a reliable substitute for an honest authorship record, and this package does not predict or guarantee a detector score.

## Suggested writing allocation (not the teacher's mandatory word count)

Abstract 120-180 words; introduction 250-350; paper summary 250-350 (one page maximum); methodology/mapping 450-650; implementation workflow 600-900; results/discussion 400-600; limitations/conclusion 150-250. Choose the final length that explains your work and follows the teacher's format.

For each section, answer the prompts in the workbook using your experience. Replace all bracketed placeholders, remove instructions, caption every chosen figure, and cite original sources. Review generated diagrams for correctness and acknowledge their preparation method. Write the final abstract last so its results match your actual tests.
