# Submission checklist - Section 1 (7.5 marks)

The provided rubric assigns 7.5 marks to paper implementation. It does not provide separate weights for the items below. This checklist supports that section; it does not claim to complete the other 7.5-mark practical section or guarantee a grade.

| Requirement | Package support | Student completion gate |
|---|---|---|
| Selected paper | `paper/Selected_Paper.pdf` | Read Sections III-VII and explain the exact conclusion direction |
| Working implementation | Unchanged v2.0.2 application, dataset and tests | Rerun on your machine and demonstrate without copying commands blindly |
| Dependencies and instructions | README, requirements, workflow guide | Verify a clean checkout can run with the installed MultiChain version |
| Actual GitHub repository | Source folder, CI and push instructions | Create/push repository; verify examiner access; submit the real link |
| Abstract and introduction | DOCX/PDF authoring workbook and prompts | Write predominantly your own text; no copied AI report |
| Methodology and architecture | Source-attributed figures and mapping | Explain each entity and trust boundary in your own words |
| MultiChain implementation workflow | Step-linked flowcharts and code index | Link each step to a command, observation and screenshot |
| Results | Supplied readiness log plus collection tools | Add demo, security and actual benchmark results; keep failures visible |
| Screenshots | Capture plan and labeled insertion locations | Capture real screens; review for secrets; add original captions |
| AI-writing limit | Authorship guidance and usage-log template | Verify compliance with the instructor; no detector guarantee |
| Final report PDF | Editable workbook only | Replace prompts, finish report and export to `submission/Implementation_Report.pdf` |

Final deliverables: original selected paper PDF, completed student-authored report PDF, actual GitHub URL. Do not submit the workbook or technical reference unchanged as the final report.
